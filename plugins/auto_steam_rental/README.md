# Auto Steam Rental

Авто-аренда Steam-аккаунтов по заказам FunPay: покупатель получает логин/пароль
сразу после оплаты, коды Steam Guard — командой `!код` в чате, по истечении
срока плагин пытается сам сменить пароль.

## Как это устроено

- Аккаунт добавляется с логином, паролем и файлом `.maFile` (из Steam Desktop
  Authenticator — там `shared_secret` для кодов Guard и `identity_secret` для
  подтверждения смены пароля).
- Лоты привязываются к аккаунтам по категории лота на FunPay (например,
  «PUBG: BATTLEGROUNDS — аккаунты») — она берётся из самого заказа
  автоматически, ничего не нужно вписывать в описание лота вручную. При
  добавлении аккаунта укажите название категории точно как на FunPay, либо
  `-`, чтобы аккаунт попал в общий пул и брался для заказов с любой
  категорией, для которой нет отдельного привязанного аккаунта.
- Отсчёт аренды начинается не с покупки, а с первого `!код` — чтобы
  покупатель, который купил и не зашёл сразу, не терял время впустую.
- Если покупатель ни разу не запросил код за grace-период — заказ
  автовозвращается, а аккаунт (пароль которого уже был показан) всё равно
  уходит на «нужен ручной сброс», на всякий случай.
- Продление: если покупатель, у которого уже есть активная или ожидающая
  аренда в этой категории, оформляет ещё один заказ на любой лот той же
  игры — плагин не ищет новый аккаунт, а добавляет время к уже идущей
  аренде и присылает подтверждение. Команда `!продление` в чате присылает
  покупателю прямую ссылку на оплату — тот же лот, что настроен для этой
  игры в авто-вкл/выкл (кнопка «⚙️ Настроить»), плюс остаток текущего
  времени аренды.
- Авто-вкл/выкл лотов настраивается по каждому лоту отдельно, парой
  «ID лота:категория» (кнопка «⚙️ Настроить»). Когда под конкретную игру не
  остаётся свободных аккаунтов — с продажи снимается только лот этой игры,
  остальные лоты продолжают работать как ни в чём не бывало. Появился
  свободный аккаунт под эту игру — лот включается обратно сам.

Подробности API/архитектуры плагинов — в [PLUGINS.md](../../PLUGINS.md) корня
проекта.
