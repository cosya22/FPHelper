# FPHelper
[![python](https://img.shields.io/badge/python-3.10%2B-yellow?style=for-the-badge&logo=python)](https://www.python.org/downloads/)
[![telegram](https://img.shields.io/badge/telegram-бот-2CA5E0?style=for-the-badge&logo=telegram)](#️-установка)

Бот-помощник для продавцов FunPay 🤖🟩

FPHelper подключается к вашему аккаунту FunPay и следит за магазином — новые
сообщения, новые заказы, изменения статуса. Управляется полностью из Telegram,
кнопками.

## ⚙️ Что умеет бот

- **🎪 Кнопочное меню в Telegram** — `/start` и дальше всё по кнопкам
- **💬 Чаты** — просмотр, ответ, отправка картинок
- **📋 Заказы** — список, детали, возврат
- **🛍️ Лоты** — включить/выключить, поменять цену
- **⬆️ Авто-поднятие лотов**
- **🚀 Авто-выдача товара** по ключевому слову в лоте (текстом или со склада)
- **⚡ Быстрые ответы** — заготовленные шаблоны сообщений
- **❗ Свои команды** — покупатель пишет `!команда` в чате, бот отвечает
- **💸 Авто-вывод средств** по расписанию (выключен по умолчанию)
- **🌟 Отзывы** — уведомления, ответ, удаление ответа
- **📊 Статистика** — заказы, выручка и сообщения за 24ч / неделю / месяц / всё время
- **🗒️ Логи** прямо в Telegram
- **📦 Установка плагинов** — присылаете `.zip` в Telegram, бот сам его подключает
- **🌐 Прокси для FunPay** — можно сменить прямо в Telegram, без переустановки конфига

## ⬇️ Установка

### 🔷 Windows
1. Установите **Python 3.10+** с [официального сайта](https://www.python.org/downloads/) (отметьте `Add to PATH`).
2. Скачайте проект и откройте папку.
3. Запустите `install.bat` — поставит всё нужное.
4. Запустите `run.bat`.

```bash
install.bat
run.bat
```

### 🍎 macOS / 🐧 Linux
1. Установите **Python 3.10+**: на macOS — `brew install python3`, на Linux — через пакетный менеджер дистрибутива (обычно уже стоит, проверить: `python3 --version`).
2. Скачайте проект и откройте папку в терминале.
3. Выполните по очереди:

```bash
chmod +x install.sh run.sh
./install.sh
./run.sh
```

### Первый запуск
Бот спросит в консоли: golden key от FunPay (F12 на funpay.com → Application
→ Cookies → `golden_key`), токен Telegram-бота (получить у [@BotFather](https://t.me/BotFather)),
ваш Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)), пароль
для бота (доп. защита сверх проверки Telegram ID) и, если нужно, прокси.
Дальше бот сам подключится к FunPay — всё управление в Telegram, доступ есть
только у вас.

После каждого перезапуска бота нужно один раз ввести `/login <пароль>` в
чате с ботом — без этого меню не откроется, даже если пишете со своего
аккаунта.

## 🧩 Плагины

Основной функционал бота уже встроен и работает сразу. Плагины — это
дополнительные платные модули поверх него, которые распространяются отдельно
(`.zip`-архивом):

- **Telegram Stars** — авто-выдача Telegram Stars через Fragment
  с автоматическим пересчётом цены ([гайд по установке](https://telegra.ph/Telegram-Stars-dlya-FPHelper-08-14))
- **Telegram Premium** — авто-выдача Telegram Premium (3/6/12 мес)
  через Fragment, тот же автопилот по цене и лотам ([гайд по установке](https://telegra.ph/Telegram-Premium-dlya-FPHelper-08-14))
- **Auto Steam Rental** — авто-аренда Steam-аккаунтов: выдача,
  коды Steam Guard, попытка авто-смены пароля по истечении аренды
  ([гайд по установке](https://telegra.ph/Steam-arenda-dlya-FPHelper-08-14-2))

По вопросам покупки — обращайтесь к автору. Устанавливаются присылкой
`.zip`-архива боту в Telegram (кнопка «➕ Установить плагин»), либо вручную —
в папку `plugins/`.

Если хотите писать свои плагины — техническое описание для разработчиков
в [PLUGINS.md](PLUGINS.md).

## ❓ Частые вопросы и ошибки

**Бот не подключается к FunPay / ошибка авторизации**
Скорее всего, golden key устарел или введён неверно. Возьмите свежий: зайдите
на funpay.com в браузере под своим аккаунтом → F12 → Application → Cookies →
`golden_key`. Введите его заново через переустановку конфига (удалите
`config.json` и запустите бота снова).

**Telegram-бот не отвечает вообще**
Проверьте, что токен от @BotFather введён без пробелов и лишних символов.
Если Telegram заблокирован в вашей стране — нужен прокси (его можно задать
при первом запуске или переустановив конфиг).

**Бот молчит, хотя всё настроено**
Доступ есть только у Telegram ID, указанного при первой настройке. Если это
не ваш ID (ошиблись при вводе) — удалите `config.json` и настройте заново.

**В логах ошибка «chat not found» при уведомлении владельцу**
Боты не могут первыми писать тем, кто ни разу не открывал с ними чат. Зайдите
к своему боту в Telegram и нажмите «Start» — после этого уведомления начнут
приходить.

**Установил плагин, а его не видно**
После установки `.zip` нужно перезапустить бота (`run.bat`), плагины
подключаются при старте.

**Python не установлен / `install.bat` ругается**
Поставьте Python 3.10 или новее с [python.org](https://www.python.org/downloads/),
при установке обязательно отметьте галочку `Add to PATH`.

**Не приходят Telegram Stars / авто-вывод не срабатывает**
Проверьте баланс кошелька и правильность введённых данных (seed-фраза,
API-ключ, cookies) — если хоть одно неверно, модуль напишет ошибку в
уведомлении. Смотрите `/logs` в боте для деталей.

**Где хранятся мои данные (golden key, токен, кошелёк)?**
Локально, в файле `config.json` и папке `storage/` на вашем компьютере. Они
никуда не отправляются, кроме FunPay/Telegram/Fragment напрямую. Никому их
не передавайте и не публикуйте.
